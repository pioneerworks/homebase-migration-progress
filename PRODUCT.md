# Product

## Register

product

## Users

The Homebase web-migration team: marketers, engineers, project leads, and reviewers who need a shared view of migration status without rebuilding reports from Linear. They use the dashboard during daily migration work, reviews, and cutover planning.

## Product Purpose

Provide a trustworthy, continuously refreshed view of URL migration progress, active work, completed pages, decisions, and parity risks. Success means the team can understand the current state, open the underlying Linear evidence, and spot movement or blockers within seconds.

## Brand Personality

Operational, precise, calm. The interface should feel as dependable and information-dense as Linear or Vercel while retaining the visual character of the existing migration artifact.

## Anti-references

Avoid celebratory KPI dashboards, decorative analytics, generic SaaS cards, excessive motion, and visuals that obscure source data. Do not imply that a route file or merged pull request equals parity completion unless its Linear URL ticket is Done.

## Design Principles

1. Lead with verifiable status and preserve links to source evidence.
2. Separate completed, active, and remaining work without hiding canceled or review states.
3. Use motion only to communicate new activity, changed status, or refresh state.
4. Keep the dashboard understandable at a glance and explorable in detail.
5. Treat access tokens and internal project data as server-side secrets.

## Accessibility & Inclusion

Target WCAG 2.2 AA contrast and keyboard usability. Provide visible focus states, semantic status labels, non-color status cues, responsive layouts, and reduced-motion alternatives for every animation.
